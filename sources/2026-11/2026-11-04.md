#### Why It Matters

- 기본 24시간 창에 포함되는 원문 직접 확인 자료입니다(직전 기록인 v2.1.316은 2026-11-02 로그에 이미 있습니다). 요청하지 않은 커넥터가 붙은 예약 작업에 대해 `/schedule`이 경고를 띄우는 기능과, 웹·셸 도구 호출이 사용자 이메일을 외부로 보낼 수 있는 경우 사전 확인을 요구하는 변경은, 이 저장소가 세션 환경에서 이미 적용받고 있는 "userEmail은 명시적 요청 없이 외부 서비스로 보내지 않는다"는 운영 규칙과 같은 방향의 플랫폼 차원 가드레일입니다. Hold의 "감사 로그와 rollback 전략이 없는 완전 자율 업무 실행" 경계, Adopt의 "제한된 범위의 코딩 에이전트(사람 승인 절차)"와 맞닿습니다.
- Agent SDK hook에 `onFailure: "block"`을 추가해 콜백 실패 시 해당 action을 막을 수 있게 한 것은, hook을 단순 로깅이 아니라 실행을 중단시키는 제어 지점으로 쓸 수 있게 한 변경으로, 10월 로그에서 반복 관찰한 "운영 통제 기능 추가" 흐름의 연속입니다.
- Claude apps gateway에 비용 리포트 엔드포인트(`GET /v1/organizations/analytics/cost`)가 추가된 것은, Watchlist의 비용·인프라 축에서 조직 단위 사용량·비용 가시성이 플랫폼 기능으로 내려오고 있다는 신호입니다.

#### Key Points

- `/schedule`이 새 클라우드 예약 작업에 요청하지 않은 커넥터가 붙으면 경고를 표시합니다.
- 웹·셸 도구 호출이 계정 이메일을 네트워크로 보낼 수 있는 경우 사전 확인 절차를 거치도록 변경했습니다.
- Agent SDK hook이 `onFailure: "block"` 옵션을 지원해, 콜백이 실패하면 해당 action을 차단할 수 있습니다.
- Claude apps gateway admin API에 비용 리포트 엔드포인트(`GET /v1/organizations/analytics/cost`)를 추가했습니다.
- Read 도구가 더 이상 "file unchanged" stub을 반환하지 않고, 변경되지 않은 파일을 다시 읽어도 실제 내용을 반환하도록 수정했습니다.
- 그 외 MCP 서버 연결 끊김, `claude auth status` 로그아웃 처리 등 다수 수정 포함.
- `github.com/anthropics/claude-code/releases/tag/v2.1.317`과 `code.claude.com/docs/en/changelog`의 2026-11-03 항목 양쪽에서 같은 변경 목록을 확인했습니다(두 원문이 서로 일치).

#### Limitations

- GitHub releases 페이지는 연도와 타임존을 명시하지 않아 "03 Nov"가 2026년이라는 점은 직전 릴리스들(v2.1.316, 31 Oct)과의 연속성, 그리고 `code.claude.com/docs/en/changelog`가 같은 항목에 "November 3, 2026"을 명시한 것으로 확인했습니다. "이메일 유출 전 확인" 기능의 구체적 트리거 조건(어떤 네트워크 요청이 걸리는지)은 changelog 요약만으로는 확인하지 못했습니다.
