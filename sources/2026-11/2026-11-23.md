#### Key Points

- `rm` 명령이 루트/홈/최상위 폴더를 대상으로 할 때 승인을 요구하도록 변경(안전장치 강화).
- 반복 예약 작업과 `/loop`의 최대 실행 기간이 7일에서 **30일로 연장**(기존에 생성된 작업은 7일 유지).
- `claude auth login` 이후 Enterprise Admin Console 설정과 클라우드 제공자/게이트웨이가 자동 적용되도록 변경.
- `easel` 내장 mod 추가 — 요청 시 차트 생성, MCP 메트릭 결과에도 차트 표시.
- VS Code에 `/fork`, `/workflows` 명령과 `contextUsageThreshold` 등 설정 추가.
- 버그 수정 98건·개선 14건(컴팩션 후 멈춤, `/rewind`가 오래된 파일을 복원하던 문제 등).

#### Limitations

- `code.claude.com/docs/en/changelog`와 GitHub releases 페이지를 각각 WebFetch로 직접 확인했습니다(high). 릴리스의 정확한 발행 "시각"은 원문에 없어 날짜 기준으로만 창 포함 여부를 판단했습니다. changelog 페이지가 길어 이번 버전 이후 세부사항 일부는 확인하지 못했을 수 있습니다.

#### My Take

- 기존 판단과 어긋나지 않습니다. `rm` 루트/홈 보호는 Hold의 "감사 로그와 rollback 전략이 없는 완전 자율 업무 실행" 판단에 부합하는 안전장치 강화 신호입니다. 반면 예약작업/`/loop` 최대 기간을 30일로 늘린 것은 장기 자율 실행을 더 길게 허용하는 방향이라, Open Questions의 "subagent orchestration은 언제 비용 대비 효과가 좋은가?"와 Trial의 "원격 sandbox 또는 격리된 terminal 기반 에이전트 실행" 항목에 구체적 관찰거리를 더합니다.

#### Why It Matters

#### Key Points

- 약 1,061 커밋, 412명 기여자 규모 릴리스. Mistral Large 4, MiniMax-M3.1-Flash, NVIDIA Nemotron-3.5-Transcribe 등 신규 모델 10종 지원 추가.
- "Extensible KV cache"가 기본값으로 전환 — 워밍업 후 가용 메모리 기준으로 캐시 크기를 자동 산정, 많은 경우 `gpu_memory_utilization` 수동 설정이 불필요해짐.
- Model Runner V1 제거, Model Runner V2가 유일한 GPU 러너로 전환(하위호환 깨짐 — `VLLM_USE_V2_MODEL_RUNNER=0` 설정 시 기동 실패).
- Breaking change: 기본 block size가 64로 변경, ROCm 7.2 이미지 미배포로 전환, `huggingface_hub>=2.0.0` 요구.
- Blackwell·MI355X에서 성능 개선(최대 디코드 속도 1.95배) 보고 — 프로젝트 자체 측정치.

#### Limitations

- GitHub 릴리스 태그 페이지를 WebFetch로 직접 열어 확인했습니다(high). 페이지 자체에 연도 표기가 없어 "16 Nov"만 확인했고, 연도(2026)는 페이지의 다른 메타데이터로 교차 확인했습니다. 성능 수치(1.95배 등)는 프로젝트 자체 보고치로 독립 검증은 없습니다.

#### My Take

- 기존 판단과 어긋나지 않습니다. 오픈웨이트 모델(Mistral Large 4 등)에 대한 서빙 지원이 빠르게 추가되는 것은 Assess의 "open-weight 모델의 폐쇄형 frontier 모델 추격" 판단을 인프라 측에서 지지하는 근거입니다 — 서빙 생태계가 신모델을 즉시 흡수하는 속도가 추격의 실질적 전제조건이라는 뜻입니다.

### Hugging Face Transformers v5.24.0 — 캐시 네이밍 통합, 신규 모델 7종 추가(Omnilingual ASR, EXAONE 공식 지원 포함)

- source_url: https://github.com/huggingface/transformers/releases/tag/v5.24.0
- published: 2026-11-21
- type: release
- topics: open-source
- status: read
- confidence: high

#### Why It Matters

- 기본 창(지난 72시간, 발행일 2026-11-21) 자료입니다. 2026-11-19 로그에 기록된 v5.23.0(2026-11-13)의 다음 버전으로, 아직 기록되지 않은 신규 릴리스입니다.

#### Key Points

- 캐시 네이밍 통합: `past_key_values`/`cache_params` → `cache`로 통일(하위호환 유지, forward는 v5.40.0까지, `generate`는 v6.0.0까지 구 이름 허용).
- 신규 모델 추가: Inkling 2 Mini(멀티모달), Apertus 1.5(텍스트+이미지+오디오→텍스트), WavTokenizer(24kHz 오디오 코덱), Dory(NVIDIA의 가변 루프 횟수 looped LM), HY4-VL(비전-언어), **Omnilingual ASR**(Meta, 1,600개 이상 언어 음성인식), Lara Mini(Translated사, 7.2B/활성 0.6B 다국어 모델, CC BY-NC-SA 4.0 비상업 라이선스, gated repo).
- EXAONE 3.0/3.5/Deep이 Llama 아키텍처 클래스를 통해 공식 지원 추가(모델 자체는 신규 아님, transformers 통합이 신규).
- Breaking change: `peft>=0.22.0` 필수, `modeling_attn_mask_utils.py` 제거(`transformers.masking_utils`로 이동), 멀티모달 생성 모델의 출력 클래스 통합, `.pt2` 익스포트 로드 시 `trust_remote_code=True` 필요.

#### Limitations

- GitHub 릴리스 태그 페이지를 WebFetch로 직접 열어 확인했습니다(high). 페이지에 연도 표기가 없어 GitHub 저작권 표기(2026)로 연도를 교차 확인했습니다.

#### My Take

- 기존 판단과 어긋나지 않습니다. Meta(Omnilingual ASR), NVIDIA(Dory), LG AI연구원(EXAONE) 등 빅테크·국내 오픈웨이트 모델이 핵심 라이브러리에 빠르게 흡수되는 추세로, Assess의 "open-weight 모델의 폐쇄형 frontier 모델 추격" 판단과 일치하는 방향입니다.
