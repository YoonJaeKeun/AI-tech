#### Why It Matters

- 기본 24시간 창에 포함되는 원문 직접 확인 자료입니다(직전 기록인 v2.1.322는 2026-11-12 로그에 이미 있습니다).
- Code Mode는 topics/agents/agents.md의 Key Concepts "Scaffolding"(모델을 둘러싼 planner, tool router 같은 실행 구조)에 해당하는 구체적인 새 설계 축입니다. 모델이 개별 tool-call을 하나씩 내보내는 대신 JavaScript 코드를 작성해 도구를 호출하도록 바꾸는 것으로, 도구 호출 방식 자체를 바꾸는 실험적 시도입니다. 아직 opt-in이고 조직이 비활성화할 수 있어, 영향 범위를 통제할 수 있는 상태로 공개됐습니다.
- 인식되지 않는 모델 ID의 기본 컨텍스트 윈도우를 200K에서 1M으로 올린 변경은 Adopt의 "LLM 전처리·후처리 경계를 명시적으로 설계하기" 판단과 맞닿습니다. 컨텍스트 예산의 기본값을 키우는 선택은 컴팩션 빈도와 비용에 직접 영향을 주는, 전처리 경계 설계의 한 사례입니다.
- Hold의 "감사 로그와 rollback 전략이 없는 완전 자율 업무 실행" 경계와 관련해, 이번 릴리스는 2026-11-09 로그(`v2.1.321`, mod 권한 자동 허용)·2026-11-09 로그의 `permissions.denyInsteadOfPrompting`과는 결이 다른 방향입니다. 오히려 `/security-review`가 실행 전에 확인을 요청하도록 바뀌고, 비밀정보로 보이는 규칙은 "don't ask again"으로 저장되지 않도록 막는 등 승인 절차를 더 엄격하게 만드는 변경이 여럿 포함됐습니다.

#### Key Points

- **Code Mode(실험적, opt-in)**: Claude가 도구를 호출할 때 JavaScript 코드를 작성하는 방식. `code.claude.com/docs/en/code-mode`에서 설정하며, 조직이 비활성화할 수 있습니다. 릴리스 노트에는 정확한 설정 이름이 명시되지 않았습니다.
- **plugin.json `engines["claude-code"]`**: 플러그인이 지원하는 Claude Code 버전 범위를 선언. 범위 밖이면 설치·업데이트·로드되지 않고, `install`/`update`는 범위에 맞는 최신 버전을 선택합니다. 범위 문법 자체는 릴리스 노트에 명시되지 않았습니다.
- **컨텍스트 기본값 변경**: 인식되지 않는 모델 ID의 기본 컨텍스트 윈도우가 200K에서 1M으로 상향(`CLAUDE_CODE_DISABLE_1M_CONTEXT=1`로 되돌릴 수 있음).
- **승인 절차 강화**: `/security-review` 실행 전 확인 요청 추가. "don't ask again"이 비밀정보처럼 보이는 규칙이나 git-tracked `settings.local.json`에 저장되는 규칙은 저장을 거부(해당 세션에서만 유효). `--permission-mode auto`가 auto mode를 쓸 수 없을 때 더 permissive한 모드로 시작하던 버그를 고쳐 Manual로 시작하도록 변경.
- **플랫폼별**: VS Code에 신뢰되지 않은 폴더에서 첫 세션 전 신뢰 prompt 추가, Slack(Claude Tag)에 Enterprise용 컴플라이언스 API 접근과 조직 비활성화 확인 단계 추가.
- `github.com/anthropics/claude-code/releases/tag/v2.1.323` 원문 전체를 WebFetch로 확인했습니다.
