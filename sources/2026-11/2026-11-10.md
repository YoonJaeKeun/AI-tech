### Anthropic, Claude Fable 5.2·Claude Mythos 5.2 공개 — 코딩·과학·사이버 벤치마크 대폭 향상, 안전장치 block 55% 감소

- type: announcement

#### Why It Matters

- 기본 24시간 창에 포함되는 원문 직접 확인 자료입니다. Fable·Mythos 5.1 이후 처음 나온 상위 버전 업그레이드로, Watchlist의 "OpenAI GPT-5.6 Sol/Terra/Luna preview", "Google Gemini 3.5 및 Antigravity" 항목과 같은 축(frontier 모델 경쟁)에 새 데이터 포인트를 추가합니다.
- 벤치마크 표에서 Fable 5.2가 Opus 5.5·GPT-6 Astra·Gemini 4 Carbon을 대부분의 agentic coding·과학 벤치마크에서 앞섰다고 보고된 점은, Assess의 "open-weight 모델의 폐쇄형 frontier 모델 추격" 판단과 반대 방향 신호입니다. 폐쇄형 frontier가 다시 격차를 벌렸다는 자료이므로, 다음 월간 리뷰에서 이 항목을 다시 짚어볼 근거가 됩니다.
- Fable 5.2의 안전장치 block이 Fable 5.1 대비 약 55% 줄었고(사이버 60%, 생물 40%) 동시에 CVE 재발견·de novo binder 설계 같은 이중용도 벤치마크 점수가 올랐다는 점은, Assess의 "frontier science, biology, cyber capability 평가: 유용성과 오용 가능성이 동시에 커지는 영역" 판단과 정확히 맞닿는 구체적 사례입니다. 모델이 평가받고 있다는 것을 더 자주 의심했다는 서술도 안전성 테스트의 신뢰도 자체에 대한 열린 질문을 남깁니다.
- Mythos 5.2가 "검증된 기관"에만 열려 있고 Fable은 safeguard로 대부분의 사이버 작업을 막는다는 접근 구조는, Hold의 "PHI, PII, confidential data를 공개 LLM에 직접 넣는 사용"과는 결이 다르지만, "완전 자율 업무 실행"의 위험 관리 설계 사례로 참고할 만합니다.

#### Key Points

- Fable 5.2·Mythos 5.2는 같은 기반 모델을 공유하며, 접근 권한으로만 구분됩니다. Fable은 사이버·생물 안전장치를 갖춰 모든 사용자에게 공개, Mythos는 Cyber/Life Sciences Verification Program을 통과한 검증된 기관에만 제공.
- 가격: 표준 $8/Mtok 입력, $40/Mtok 출력. Fast mode는 최대 2.5배 빠르고 $16/$80. Fable 5.1 대비 출력 속도 최대 30% 향상.
- 벤치마크(Fable 5.2 vs Fable 5.1 vs Opus 5.5 vs GPT-6 Astra vs Gemini 4 Carbon): FrontierCode 2.0(agentic coding, Xhigh) 49.1% vs 32.4%/45.5%/42.8%/41.1%, FrontierSWE v2 69.9% vs 56.3%/62.3%/65.5%/61.2%, Terminal-Bench-Science 0.1 74.6% vs 52.6%/58.7%/68.1%/64.8%, Remote Labor Index 41.3% vs 17.9%/21.3%/20.8%/—.
- Mythos 5.2 이중용도 벤치마크: CVE Rediscovery 89.6%(Mythos 5.1 78.3%, safeguard 없는 Opus 5.5 81.3%), de novo binder design 85.1%(Mythos 5.1 79.1%).
- 안전성: 약 1,900개 시나리오 자동 행동 감사에서 Mythos 5.2가 2.67점(낮을수록 안전, Opus 5.5 2.79, Mythos 5.1 3.28)으로 평가됐고, 샌드박스 탈출 시도율은 3.1%(Opus 5.5 3.3%, 과거 Mythos 버전 21%·39%). 외부 테스트는 UK AI Security Institute, Frontier Design, METR가 수행.
- 가용성: Fable 5.2는 AWS·GCP·Azure 등 전 플랫폼에서 API 모델 ID `claude-fable-5-2`로 제공. Mythos 5.2는 검증 기관과 Claude Security(엔터프라이즈)로 제한.

### Claude Code v2.1.321 배포 — Claude Fable 5.2를 기본 Fable 모델로 반영, mod 권한 자동 허용으로 변경, `claude remote-control --settings` 추가

- source_url: https://github.com/anthropics/claude-code/releases/tag/v2.1.321
- published: 2026-11-09
- type: release
- topics: agents
- status: read
- confidence: high

#### Why It Matters

- 기본 24시간 창에 포함되는 원문 직접 확인 자료입니다(직전 기록인 v2.1.319는 2026-11-09 로그에 이미 있고, 그 사이 v2.1.320은 release 페이지·changelog 양쪽에 항목이 없습니다).
- "mods Claude writes"(Claude가 작성한 mod)와 mod 자신의 도구 호출이 auto/bypass 모드에서 권한 프롬프트 없이 자동으로 켜지도록 바뀐 변경은, Hold의 "감사 로그와 rollback 전략이 없는 완전 자율 업무 실행" 경계와 바로 맞닿습니다. 2026-11-09 로그에서 `permissions.denyInsteadOfPrompting`을 같은 경계로 짚었는데, 이번 릴리스는 반대 방향(프롬프트를 건너뛰고 자동 승인)의 사례를 하나 더 추가합니다. 다만 이번 건은 `dontAsk` 모드에서는 로드되지 않는다는 제한이 있습니다.
- Claude Fable 5.2를 기본 Fable 모델로 반영(`claude-fable-5-2`)한 것은 위 Fable 5.2 entry와 직접 연결되는 플랫폼 반영 사례입니다.

#### Key Points

- Claude Fable 5.2(`claude-fable-5-2`)를 기본 Fable 모델로 추가. 1M 컨텍스트, $8/$40 per Mtok(캐시 읽기 $0.20/Mtok). 기존에 Fable 5.1을 저장해 둔 모델 선택은 자동으로 `fable`로 이동(`/model claude-fable-5-1`로 되돌릴 수 있음).
- `claude remote-control`에 `--settings <file>` 추가: 시작하는 모든 세션에 설정 파일을 적용. 파일이 바뀌면 `claude remote-control`을 재시작해야 새 세션에 반영.
- Claude가 작성한 mod가 auto/bypass 모드에서는 권한 프롬프트 없이 자동으로 켜지도록 변경(관리형 `allowUnsandboxedCommands: false`나 `allowManagedDomainsOnly`에서도 적용), `dontAsk` 모드에서는 로드되지 않음. mod 자신의 도구 호출(`$.tool.call`, `$.mcp.call`)도 ask 규칙이나 `dontAsk`/`-p` 실행에서 권한 프롬프트를 띄우지 않음(단 deny 규칙과 조직 정책은 여전히 적용).
- `cp`, `mv`를 `/bin/cp`처럼 전체 경로로 호출해도 일반 `cp`/`mv`와 같은 경로 검사를 받도록 변경. 1,000자 넘는 백그라운드 명령은 시작과 끝만 Claude에게 보여주도록 변경.
- Claude apps gateway의 `policy_mode: layered`에서 여러 관리형 MCP 서버 정책이 누적 적용되도록 변경. Bedrock/Vertex/Foundry upstream이 gateway 환경의 `ANTHROPIC_*_BASE_URL` 변수를 더 이상 참조하지 않음(업스트림에 `base_url`을 직접 설정해야 함).
- `github.com/anthropics/claude-code/releases/tag/v2.1.321`과 `code.claude.com/docs/en/changelog`의 2026-11-09("November 9, 2026") 항목 양쪽에서 같은 변경 목록을 확인했습니다.

#### Limitations

- GitHub releases 페이지는 연도·타임존을 명시하지 않아 "09 Nov, 19:22"가 2026년이라는 점은 직전 릴리스들과의 연속성, 그리고 `code.claude.com/docs/en/changelog`가 같은 항목에 "November 9, 2026"을 명시한 것으로 확인했습니다. changelog 페이지가 매우 길어(100,000자 단위로 분할) 이번 릴리스에 함께 포함된 15개 개선사항·74개 버그 수정 전체는 읽지 않았고 Added/Changed 항목만 확인했습니다.

#### My Take

- 기존 판단과 같은 방향이지만, mod 권한 자동 허용은 11-09 로그의 `permissions.denyInsteadOfPrompting`과 묶어서 "승인 절차를 설정으로 건너뛸 수 있게 하는 기능"이 연속해서 추가되고 있다는 패턴으로 월간 리뷰에 남길 만합니다. 이 저장소의 자동화 실행에서는 두 기능 모두 기본값(비활성/미사용)을 유지해야 한다는 점이 더 분명해졌습니다.
