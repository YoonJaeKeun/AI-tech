#### Why It Matters

- 기본 72시간 창에 포함되는 원문 직접 확인 자료입니다(v2.1.314는 30 Oct, v2.1.316은 31 Oct 공개. 직전 기록인 v2.1.312는 10-28 로그에 이미 있습니다). `permissions.blockWritesOutsideWorkingDirectories`(모든 권한 모드에서 Write·Edit·NotebookEdit이 작업 디렉터리 밖 경로를 거부)는 Hold의 "감사 로그와 rollback 전략이 없는 완전 자율 업무 실행" 경계와 맞닿는 운영 통제 기능으로, 이 저장소가 세션별로 scratchpad 경로를 강제하는 운영 방식과도 같은 방향입니다.
- VS Code·Claude Desktop의 idle compaction(200K 토큰을 넘겨 멈춘 대화를 자동 요약)은 10-26~29 로그에서 반복 관찰한 "컨텍스트 예산 관리·압축 견고화" 흐름의 연속으로, Adopt의 LLM 전처리·후처리 경계 설계(`topics/llm-pipeline`)가 다루는 실패 유형(컨텍스트 과다로 인한 중단)을 줄이는 변경입니다.
- Opus 4.8 fast mode를 2026-10-30부로 deprecated 처리하고 2026-11-30 제거 예정으로 공지한 것은, Watchlist의 모델 세대교체 흐름(Claude Sonnet 5 계열 실사용 평가) 위에서 구형 모델 경로가 구체적으로 폐기되는 첫 사례입니다.

#### Key Points

- v2.1.314(30 Oct): `permissions.blockWritesOutsideWorkingDirectories` 추가. Claude apps gateway upstream에 IdP 그룹 제한(`groups`) 라우팅 추가. VS Code·Claude Desktop Code 탭에 idle compaction(200K 토큰 초과 대화를 유휴 시 요약, prompt cache 만료 시 다음 메시지에 적용) 추가. effort 레벨을 admin이 제한했을 때 세션이 실패하지 않고 낮춰서 재시도하도록 수정. Bedrock에서 이미지 다수 포함 세션이 "Input is too long" 대신 오래된 이미지를 제거하고 compact하도록 수정.
- v2.1.316(31 Oct): `CLAUDE_CODE_DISABLE_ULTRATHINK`, `CLAUDE_CODE_SUBAGENT_EFFORT`(서브에이전트 기본 effort 레벨 지정), Claude apps gateway의 pooled group budgets(그룹 공유 월 예산)·`managed.policy_mode: layered`(여러 policy를 순서대로 누적 적용)·Bedrock guardrail용 `guardrail.input_tagging` 추가. Opus 4.8 fast mode가 2026-10-30부로 deprecated, 2026-11-30 제거 예정(제거 후에는 standard Opus 4.8로 자동 전환되지 않고 오류 반환) 공지, Opus 5.5로 마이그레이션 권고. 그 외 셸·훅·세션 복구 관련 다수 안정성 수정(약 60개 항목).
- `github.com/anthropics/claude-code/releases/tag/v2.1.314`, `tag/v2.1.316` 원문을 직접 열어 전체 changelog를 확인했습니다.
