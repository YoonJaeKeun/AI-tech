#### Why It Matters

- 기본 창(지난 24시간, 발행일 2026-11-26) 자료입니다. 2026-11-23 로그에 기록된 b12642~b12651 자동빌드와 이번에 확인한 b12779~b12800 자동빌드 사이에 나온, 자동빌드와는 별개로 기록할 가치가 있는 의미 있는 마이너 버전 릴리스입니다.

#### Key Points

- 기존 `llama_batch` API deprecated, `llama_batch_ext` 사용 권장. 양자화에 `target_bpw`/`target_size` 파라미터 추가(목표 bpw·파일 크기에 맞춘 자동 양자화).
- 신규 모델 지원: Inkling 2 계열(base/Mini/DSpark), Domyn Edge 4B, Zaya1 8B, MiniMax-M3.1, RAON-1-mini, Hy4 flash 등. TTS/오디오: Kokoro, Zonos3-Mini, VoxCPM2, Kyutai Hibiki 등.
- 채팅 파싱이 텍스트 매칭 대신 특수 토큰 기준으로 전환, named tool_choice 지원 추가.
- `llama-server`: 슬롯 스케줄링 리팩터링, `--ui-agent` 옵션, `/models/sse` 엔드포인트 추가.
- Web UI가 "Llama Chat"으로 재설계(음성 메시지, 에이전트 실행 기록 표시 포함), `npx @ggml-org/llama-chat`로 독립 실행 가능.
- 의존 ggml 버전 → v1.1.1.

#### Limitations

- GitHub 릴리스 페이지와 `releases.atom` 피드를 WebFetch로 직접 열어 확인했습니다(high). 릴리스 페이지 자체에는 연도가 표기되지 않아 atom 피드의 `<updated>` 값(UTC 2026-11-26 09:16)으로 발행일을 교차 확정했습니다. 릴리스 페이지가 매우 길어 뒷부분 커밋 목록 일부는 열람하지 않았습니다.

#### My Take

- 기존 판단과 어긋나지 않습니다. `--ui-agent` 옵션과 에이전트 실행 기록을 보여주는 Web UI 재설계는 Trial의 "원격 sandbox 또는 격리된 terminal 기반 에이전트 실행" 판단과 약하게 연결됩니다. Adopt의 "LLM 전처리·후처리 경계 설계"와는 직접 연결되지 않습니다.
