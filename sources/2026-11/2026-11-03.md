#### Why It Matters

- 기본 24시간 창에 포함되는 원문 직접 확인 자료입니다. 직전 기록된 v0.32.0(18 Oct, 기존 로그)에서 두 단계 건너뛴 릴리스로, 서빙 스택의 하드웨어·의존성 요구사항이 한 번에 여러 축에서 올라간 사례입니다.
- CUDA 12.9 wheel·이미지 중단(CUDA 13.0만 지원)과 ROCm 10.0 기본 전환은 Watchlist의 "비용·인프라·서빙" 흐름에서, 자체 서빙(vLLM) 비용이 하드웨어/드라이버 업그레이드 비용과 함께 올라갈 수 있다는 구체적 신호입니다.
- Medusa·MLP speculator·레거시 Ray compiled-graph executor 제거, `--mamba-cache-mode` deprecated 등은 기존 배포 파이프라인이 다음 업그레이드 때 코드 수정 없이 넘어갈 수 없는 breaking change로, "제한된 범위의 코딩 에이전트"가 의존성 업그레이드 자동화에 쓰일 때 검증해야 할 구체적 범위를 넓힙니다.

#### Key Points

- 927 commits, 389 contributors(122명 신규). 신규 모델 지원 약 12종(Reflection Beam-1.0, Yandex AliceAI-Foundation-80B-A3B, Recursive Flint, Muse Spark Open, Step-5 Preview, NVIDIA Alpamayo 2 Super 및 NVIDIA Nemotron 변종 다수).
- 의존성: PyTorch 2.14, torchvision 0.29.0, Triton 3.8.0. CUDA 12.9 wheel·이미지 배포 중단(CUDA 13.0만 지원). AWS EFA 이미지 신설, 모든 릴리스 이미지가 짧은 `vllm/vllm` 이름으로도 배포.
- speculative decoding: 새 refiner·검증 정책, 양자화된 draft `lm_head` 지원, EAGLE/MTP draft용 prefix-cache 개선. NVIDIA: GB300·Hopper 디코드 속도 개선, Blackwell에서 FlashMLA·FlashInfer 개선, context parallelism용 CUDA graph 지원. AMD ROCm: ROCm 10.0 기본 이미지 전환(ROCm 7.2는 `-rocm72`로 별도 제공), MonoKernel decode·신규 KV cache 타입 추가.
- API·서빙: `/v1/decisions` 엔드포인트, late chunking 기반 token embedding, Rust 프런트엔드 추진, 동시 worker 시작 속도 개선, 멈춘 프로세스 감시용 watchdog 추가.
- Breaking change: Medusa·MLP speculator 제거, 레거시 Ray compiled-graph executor 제거, `--mamba-cache-mode` deprecated, paused generation 중 요청은 이제 HTTP 503 반환, NIXL connector는 NIXL 1.5+ 필수, LM Format Enforcer·`--ir-op-priority` deprecated.
- `github.com/vllm-project/vllm/releases/tag/v0.33.0rc3` 원문을 직접 열어 하이라이트와 카테고리별 변경 노트를 확인했습니다(전체 PR 목록·기여자 명단까지는 다 읽지 못함).

#### Limitations

- GitHub releases 페이지는 연도를 명시하지 않아 "02 Nov, 10:10"이 2026년이라는 점은 당일 함께 올라온 다른 저장소(llama.cpp b120xx, 2026-11-02 명시)와의 연속성으로 추정했습니다. 릴리스 태그가 `v0.33.0rc3`(release-candidate 명명)이면서 releases 목록에는 "v0.33.0"으로 "Latest"로 표시되어, 이것이 정식 stable인지 RC인지 페이지 자체로는 명확히 구분되지 않았습니다. 하이라이트는 vLLM 메인테이너의 자체 요약이며 각 변경의 독립적 재현·검증은 하지 않았습니다.
