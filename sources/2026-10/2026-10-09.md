- 같은 날(2026-10-08) Claude Agent SDK도 parity 릴리스를 냈습니다: Python v0.2.165는 내장 CLI를 2.1.294로 업데이트했고, TypeScript v0.3.294/v0.3.295는 `SDKRateLimitInfo`에 `overageEnabled` 필드 추가, MCP tool 목록이 stale 상태로 남는 버그 수정, 스트리밍 중 citation이 누락되는 버그 수정, tool-search 설명 길이 제한을 CLI와 동일하게(16,384자) 동기화했습니다.

- Model Runner V2가 드래프트 모델 기반 투기적 디코딩과 커스텀 로짓 프로세서를 지원하며, 새 LiLiCorr 드래프터와 Gemma4용 적응형 검증(DSpark)이 추가됐습니다.

- published: 2026-10-06

- confidence: medium

#### Why It Matters

#### Key Points

- EmbeddingGemma2: Google이 Gemma 4 아키텍처로 만든 멀티모달 임베딩 모델로, 텍스트·이미지·오디오·비디오를 하나의 768차원 벡터 공간에 넣고 Matryoshka 표현 학습으로 512·256·128차원까지 잘라 쓸 수 있습니다. 쓰지 않는 비전·오디오 모듈은 로드 시 비활성화해 메모리를 아낄 수 있습니다.
- Breaking change: 라우터 로짓을 계산하는 모든 MoE 모델이 `output_router_logits=True`일 때 이를 반환하도록 바뀌어, 기존 출력 형식에 의존하던 코드는 새 출력 클래스로 수정해야 합니다.
- 그 외 breaking change: OWLv2의 이미지 쿼리 박스 선택이 objectness 점수 기준으로 바뀌었고, SDPA/flash attention의 `"paged|"` 접두사가 deprecated됐습니다.

#### Limitations

- github.com/huggingface/transformers/releases/tag/v5.19.0 원문을 직접 열어 확인했습니다(status: read). 페이지에 발행 "연도"가 명시돼 있지 않아("10월 6일 16:39", 페이지 하단 "© 2026"은 사이트 저작권 연도일 뿐) 인접 릴리스 날짜 흐름으로 2026년으로 추정했습니다. 이 추정 때문에 confidence를 medium으로 낮췄습니다.

#### My Take

- 기존 판단과 같은 방향입니다. 멀티모달 임베딩이 Matryoshka 방식으로 차원을 조절 가능하게 나온 것은, Trial의 "추론 effort를 조절하는 모델 선택 전략"과 유사한 "정밀도/비용을 조절하는" 설계가 임베딩 레이어까지 내려온 사례로 볼 만합니다.
