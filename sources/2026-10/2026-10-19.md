#### Key Points

- v2.1.302(16 Oct) 추가: `CLAUDE_CODE_AUTO_MODE_MODEL`로 클라이언트 측 auto mode 분류기 모델을 별도 지정 가능(서버 측 auto mode 모델에는 영향 없음); `/config`에 idle compaction on/off 토글 행 추가; `/design-sync`·`/design-login`에 standalone Claude Design이 2026-12-14 종료된다는 경고 추가; cloud routine이 조직의 동시 cloud session 한도 도달 등으로 마지막 실행이 시작되지 못한 이유를 배너로 표시.
- v2.1.302 변경: 퍼미션 모드를 지정하지 않은 `claude -p`·Agent SDK 세션이 서드파티 provider에서 기본 `default` 모드로 시작(`--permission-mode auto`를 명시해야 예외); fork subagent(`subagent_type: "fork"`)가 `claude -p`, Agent SDK, desktop app, VS Code에서 기본 활성화(`CLAUDE_CODE_FORK_SUBAGENT=0`으로 끌 수 있음); prompt·agent hook이 이벤트당 최대 12개까지 동시 실행; Claude Tag 관리자 설정이 Bundles/Connectors/Skills and plugins/Channels 4개 탭으로 재구성.
- v2.1.302 버그 수정(43건 중 일부): compaction 중 turn이 중단될 때 "Prompt is too long" 오류가 나던 문제; Read 도구가 큰 이미지 파일을 통째로 메모리에 올리던 문제를 고치고 128MB를 초과하는 이미지 소스는 이제 거부; 게이트웨이가 모델명에 프리픽스를 붙일 때 `/effort`·`/autocompact` 설정이 잘못된 모델에 저장되던 문제; Windows에서 exFAT·FAT32 드라이브의 모든 파일 쓰기가 거부되던 버그; Claude in Slack이 단일 Slack 조회가 멈췄을 때 DM에 "일시적으로 사용 불가"로만 응답하던 문제.
- v2.1.303(18 Oct)은 "버그 수정과 안정성 개선"으로만 요약돼 있고 changelog 페이지 자체에 세부 변경 목록은 공개되지 않았습니다.

### Ollama v0.40.6~v0.40.7-rc0 — decision model(clef)을 Ollama 클라우드로 확장, Windows orphaned runner 방지, GGUF q2_0 타입 추가

- source_url: https://github.com/ollama/ollama/releases/tag/v0.40.6
- published: 2026-10-16
- type: release
- topics: open-source
- status: read
- confidence: high

#### Why It Matters

- 기본 72시간 창에 포함되는 원문 직접 확인 자료입니다. 10-15 로그가 기록한 decision model CLI 통합(`ollama run --ask`, v0.40.1~v0.40.5-rc0) 흐름이 그 다음 주에도 이어지는 것을 확인했습니다. CURRENT.md Trial의 "추론 effort를 조절하는 모델 선택 전략"에 계속 닿는 로컬/클라우드 하이브리드 서빙 변경입니다.

#### Key Points

- v0.40.6(16 Oct, stable, Latest로 표시): Windows에서 고아(orphaned) runner 프로세스가 남는 문제를 방지; GGUF에 `q2_0` tensor·file type을 추가; decision model `clef`를 Ollama 클라우드 자체 서비스로 출시; `--ask` 모드 질문 키에 식별자를 사용하도록 변경.
- v0.40.7-rc0(18 Oct, pre-release): Responses API의 effort 설정을 non-thinking 모델에도 허용; `llama-server`가 draft speculative 디코딩 타입을 자동으로 추론; MLX에 PPLX Decider v1.2 지원 추가.
- 10-15 로그가 기록한 v0.40.5(14 Oct, decision model `clef`·`clef-flash`를 Ollama 클라우드를 통해 제공하기 시작한 버전)에 이어, v0.40.6에서 `clef`가 클라우드 서비스로 정식 확장된 것으로 보입니다.

#### Limitations

- `github.com/ollama/ollama/releases` 원문을 직접 열어 확인했습니다(status: read). 페이지의 릴리스 날짜 표기에 연도가 없어("16 Oct", "18 Oct") 애셋 타임스탬프와 인접 릴리스 흐름으로 2026년으로 추정했습니다(이전 로그들과 같은 추정 방식). v0.40.7-rc0은 pre-release라 정식 반영 전 변경될 수 있습니다. "PPLX Decider"의 구체적 아키텍처·"clef" decision model의 내부 구조는 릴리스 노트만으로 확인하지 못했습니다.

#### My Take

- 기존 판단과 같은 방향입니다. decision model이 CLI 통합(10-12·10-15 로그)을 넘어 벤더 자체 클라우드 서비스(Ollama 클라우드의 `clef`)로 확장되는 것은, "decision model 개념이 로컬 오픈소스 런타임까지 확산된다"는 기존 관찰이 로컬-클라우드 하이브리드 서빙 쪽으로 한 단계 더 나아가고 있다는 신호입니다. open-source 축에서 Ollama의 거의 매주 단위 릴리스 패턴이 계속되고 있어 다음 로그에서도 지켜볼 가치가 있습니다.
