### Anthropic Claude Code, v2.1.288~289 배포 — 모드/플러그인 설정 기능 확장, 다수 플러그인·세션 안정성 수정

- source_url: https://code.claude.com/docs/en/changelog
- published: 2026-10-03
- type: changelog
- topics: agents
- status: read
- confidence: high

#### Why It Matters

- 기본 72시간 창에 포함되는 원문 직접 확인 자료입니다. 2026-10-02 로그에서 기록한 v2.1.287에 바로 이어지는 다음 두 버전으로, CURRENT.md Adopt의 "제한된 범위의 코딩 에이전트"·"LLM 전처리·후처리 경계를 명시적으로 설계하기" 판단과 관련된 실행 하네스 안정성 개선이 계속되는 동시에, Trial의 "subagent orchestration" 판단과 맞물리는 플러그인·mod 확장 기능이 이번에도 추가됐습니다.

#### Key Points

- v2.1.288(10-02)에서 mod용 `$.ui.selection()`(풀스크린 모드에서 마지막 선택한 텍스트 반환), GitHub CLI가 없는 클라우드 세션에 내장 `gh api` 추가, Ctrl+C로 지운 프롬프트를 Up 키로 복구하는 기능, MCP 서버가 도구 호출 중 추가 OAuth 스코프를 요청할 때 재인증 프롬프트, `/code-review`에 `--max-findings <n>|all` 옵션이 추가됐고, 120개 이상의 버그 수정(API 타임아웃, 세션 재개, 권한 규칙 처리, 플러그인 로딩 등)이 있었습니다.
- v2.1.289(10-03)에서는 복합 셸 명령의 중첩된 부분에 대한 deny/ask 규칙이 관리되는 머신에서 사용자 설치 mod 승인을 넘어서지 못하던 버그, 닫히지 않은 `<script>` 태그가 많은 짧은 코드 블록에서 터미널이 멈추던 버그, IDE에서 심링크로 연결된 파일에 `Read` deny 규칙이 적용되지 않던 버그 등이 수정됐습니다. teammate용 `agent.spawn`, plugin 간 공유되는 단일 agent id, `$.agent.list()`의 idle/waiting 상태가 추가됐습니다.

#### Limitations

- code.claude.com/docs/en/changelog 원문을 직접 열어 확인했습니다(status: read). "120개 이상의 버그 수정"으로 요약된 v2.1.288의 세부 항목은 분량상 축약했고, 두 버전이 실제로 언제부터 일반 사용자에게 순차 배포됐는지는 확인하지 못했습니다.

#### My Take

- 기존 판단과 같은 방향입니다. 2026-09-29~10-02 로그에서 이어진 거의 매일 단위의 세션·플러그인 안정성 개선 패턴이 계속되고 있고, mod/plugin API가 매 버전 조금씩 넓어지는 흐름은 Trial의 subagent orchestration 판단과 Watchlist의 MCP 거버넌스 항목 모두와 계속 맞닿아 있습니다.
