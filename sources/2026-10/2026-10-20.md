#### Why It Matters

- 기본 24시간 창에 포함되는 원문 직접 확인 자료입니다. 10-19 로그가 기록한 v2.1.302~303에 바로 이어지는 버전으로, Adopt의 "제한된 범위의 코딩 에이전트: 테스트, diff review, 사람 승인 절차가 있는 저장소 작업" 판단과 직접 맞닿는 두 변경(Code Review 레벨, `decider: "person"`)이 들어 있습니다.

#### Key Points

- [Code Review] 조직 관리자가 전사 기본 리뷰 수준을 Quick/Standard(기본값)/Deep 중에서 고르고, 개별 저장소에 따로 수준을 지정할 수 있게 됨. 또한 GitHub organization 전체(이후 추가되는 저장소 포함)를 하나씩 선택하지 않고 한 번에 Code Review 대상으로 켤 수 있는 옵션 추가.
- mod(hook) API에 `tool.check` 응답으로 `decider: "person"` 추가: 권한 다이얼로그나 호스트 콜백만 그 도구 호출을 승인할 수 있고, 물어볼 사람이 없으면 mod가 적은 이유로 자동 거부됨. 즉 "사람 승인 절차"를 mod 레벨에서 강제할 수 있는 장치.
- `/auto-mode-setup`(프로젝트·최근 세션을 읽어 auto mode에 환경을 알려주는 가이드 설정)이 Bedrock, Vertex, Foundry, Claude apps gateway, telemetry 비활성 세션까지 확대됨.
- Pro/Max 플랜에서 비활성 대화를 재개할 때 5시간 사용량 한도의 상당 부분을 쓰게 되면 경고를 표시하도록 추가.
- 세션 압축 요약에 이전에 호출한 도구 이름을 트랜스크립트 뷰(Ctrl+O)에 추가 표시; 서브에이전트 다수 동시 실행 시 응답성·처리량 개선; 장시간/재개된 대화에서 메모리 사용 개선.
- 버그 수정 다수(약 40건) 중 보안·안정성 관련: `sandbox.filesystem.denyRead` glob에 문자 클래스가 아닌 대괄호(예: `[user-id]` 라우트 폴더)가 있을 때 Linux 샌드박스 명령이 시작하지 못하던 문제 수정; 마운트된 드라이브나 `/Volumes`, `/media`, WSL `/mnt/c` 최상위 폴더에서의 `rm -r`에도 `rm -rf /Applications`와 같은 안전 확인 프롬프트가 뜨도록 수정; 헤드리스 실행에서 플러그인이 서브에이전트를 계속 만들어 `--max-turns`/Stop/입력 종료를 넘겨 실행이 이어지던 문제 수정.
- `code.claude.com/docs/en/changelog`와 `github.com/anthropics/claude-code/releases` 두 원문으로 버전(v2.1.304)과 날짜(2026-10-19, GitHub 기준 21:34 게시)를 교차 확인했습니다.
