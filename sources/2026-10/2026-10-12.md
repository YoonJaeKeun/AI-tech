- published: 2026-10-09
- type: changelog
- topics: agents
- status: read
- confidence: high

#### Why It Matters

- 기본 72시간 창에 포함되는 원문 직접 확인 자료입니다. 2026-10-09 로그에서 기록한 v2.1.294~295에 바로 이어지는 버전으로, CURRENT.md Adopt의 "제한된 범위의 코딩 에이전트" 판단과 맞닿은 하네스 안정성·정책 변경이 계속되는 사례입니다.

#### Key Points

- 가격: Sonnet 5.5의 cache-read 가격 인하($0.20→$0.10/M, 2026-10-08 Haiku 5.5 발표에서 예고된 내용)가 `/cost`, 상태줄, `--max-budget-usd`, SDK 비용 수치에 반영됐습니다.
- 추가: subagent frontmatter·`--agents` 정의에 `autoCompactWindow`, 모든 workflow agent를 하나의 모델로 고정하는 `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`, 529(overloaded) 재시도 최대 backoff를 늘리는 `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS`, Read tool의 대용량 텍스트 파일 단일 호출 읽기 옵션(`allow_large`).
- 변경: MCP tool 설명·서버 instruction 기본 길이 제한이 2,048자에서 4,096자로 늘었고, 세션이 백그라운드로 전환될 때 실행 중이던 turn이나 `!` 명령이 "보이지 않는 채로 계속 끝까지 실행"되지 않고 중단되도록 바뀌었습니다. VS Code의 Claude in Chrome은 매 세션마다 브라우저 동작 전에 확인을 묻습니다.
- 수정: managed-settings hook이 `"continue": false`로 거부했을 때 turn이 예기치 않게 끝나버리던 버그, 1KB 이상 PowerShell 명령이 권한 검사를 제대로 받지 않던 Windows 버그, Edit/NotebookEdit이 non-UTF-8 파일을 수정하려 할 때 비-ASCII 문자를 깨뜨리던 버그.

#### Limitations

- code.claude.com/docs/en/changelog 원문을 직접 열어 확인했습니다(status: read). 페이지 분량이 매우 커(약 105만 자) 앞부분(문자 0~100,000, v2.1.296 항목 전체 포함)만 읽었습니다. 실제 일반 사용자 순차 배포 시점은 확인하지 못했습니다.

#### My Take

- 기존 판단과 같은 방향입니다. 세션이 백그라운드로 넘어갈 때 실행 중 명령을 "보이지 않게 계속 끝까지 실행"하지 않고 중단시키는 변경은, Adopt의 "사람 승인 절차가 있는 저장소 작업" 전제에서 감시되지 않는 실행을 줄이는 방향이라 긍정적으로 봅니다. 거의 매일 단위의 안정성·정책 조정 패턴이 10월 내내 이어지고 있습니다.

#### Key Points

- 기존 Project Glasswing과 CVP를 통합해 Defense Access(방어 작업, 다수 기관 대상, 수일 내 승인), Red Team Access(승인된 침투 테스트·red-teaming, 기관 전용, 수주 소요), Specialized Access(전력망·항공 운항 시스템 등 안전критical 시스템 테스트 승인 기관 전용, 미국 정부와 심층 심사) 3단계로 재편했습니다.
- 각 티어에는 Claude Opus 5.5, Claude Sonnet 5.5, Claude Mythos 5.1, 향후 모델이 포함됩니다. Claude Platform, Google Cloud Vertex AI, Microsoft Foundry에서 제공되며 Amazon Bedrock은 Enterprise Frontier Safeguards 대상 고객으로 제한됩니다.
- 성과: Glasswing 파트너들이 2026년 4~7월 사이 최소 129,000건의 검증된 소프트웨어 취약점을 발견했고, Anthropic 자체 오픈소스 스캔으로 4~10월 사이 5,500건을 추가 발견했습니다. 이 중 33,000건 이상이 critical/high 심각도로 분류됩니다(Anthropic은 실제 영향이 최소 5배 더 클 것으로 추정한다고 밝힘).
- 등록 기관은 오용 모니터링을 위해 데이터를 보관해야 하며, 2026년 가을 예정된 Enterprise Frontier Safeguards가 적격 기관이 자체 통제 인프라에 데이터를 저장하게 해줄 예정입니다.

#### Limitations

- anthropic.com/news/cyber-verification-program 원문을 직접 열어 확인했습니다(status: read). 다만 본문에 언급된 "Claude Mythos 5.1" 자체의 공식 출시 발표 페이지는 이번 검색에서 찾지 못했습니다. 2차 보도(forklog.com, decrypt.co, sdtimes.com)만 확인했고 정확한 출시일이 서로 다르게(2026년 9월 초~10월 초) 보도돼, 모델명만 이 entry에 교차 확인 없이 그대로 인용했습니다. 129,000건·5,500건·33,000건 수치는 Anthropic 자체 보고치이며 독립 검증은 없습니다.

#### My Take

- 기존 판단과 같은 방향이면서 Open Questions에 구체적 재료를 더합니다. "안전장치를 완전히 끄는 것"이 아니라 "기관 심사 단계별로 안전장치를 조절"하는 설계는, open-weight 모델 논의에서 반복되는 "안전장치 제거 가능성" 우려에 대한 폐쇄형 벤더의 대안적 접근으로 볼 만합니다. 다만 Specialized Access의 "미국 정부와 심층 심사"가 구체적으로 어떤 기준인지는 이 발표만으로는 알 수 없어 지켜볼 필요가 있습니다.
