- LiquidAI의 LFM3 계열(LFM3-1.7B, LFM3-VL-2B, LFM3-Audio-2B, LFM3-Omni-2B, d1-2B, d1-omni-2B) 6종을 한 릴리스에서 동시 지원한 것은, 10-16 로그에서 짚은 "신모델 출시 당일/직후 지원" 패턴이 멀티모달·omni 계열로 확장되는 사례입니다.
- `/v1/realtime`, `POST /tts` 엔드포인트 추가는 로컬 추론 엔진이 텍스트 생성을 넘어 실시간 음성 대화·TTS까지 서버 기능으로 흡수하고 있다는 신호로, Trial의 "추론 effort를 조절하는 모델 선택 전략"이 다루는 범위를 음성 모달리티로 넓힙니다.
- DeepSeek V4.1 Flash 지원이 이번 릴리스에서 공식 확인됐습니다. 10-26 로그에서 "DeepSeek-V4.1-Flash-1017" 표기를 단일 애그리게이터 출처(`pricingsaas.com`)만으로는 교차 확인하지 못해 제외했는데, 이번에 llama.cpp 원문에서 모델명이 직접 확인됐습니다.

#### Key Points

- 신규 모델 지원: LiquidAI LFM3 계열 6종, DeepSeek V4.1 Flash, SenseNova U1, Beam, Kolibri-1, Flint, Muse Spark Open, Granite Switch Decision, Nemotron-3(.5)-Embed, H2O-Lightning-4B, MiniCPM-OCR 1.0/Jev, Soprano TTS.
- 서버: `/v1/realtime`(대화·전사·tool call 지원), `POST /tts` 엔드포인트 신설. `mtmd` 라이브러리에 실험적 streaming-audio API 추가. reasoning effort level을 chat template에서 API로 노출. LAN 밖 peer-to-peer 접근을 위한 `--connect` 플래그 추가.
- Web UI: Hugging Face Hub에서 모델 검색·다운로드, 대화·메시지 검색, 긴 대화 압축(compact) 기능 추가. 모델 매니저가 독립 라우트로 분리, OGG 오디오 첨부 지원.
- 동작 변경(주의 필요): CLI에서 `--model` 또는 `-hf` 지정이 이제 필수(누락 시 실패). grammar recursion depth 강제, JSON 128단계 초과 중첩 거부.
- 성능: MoE expert 호스트 메모리 캐시를 LRU에서 50/50 SLRU로 변경. CUDA chunked graph launch, fused MoE top-k(최대 384 experts), fused gate/up·GLU matmul. SYCL graph record/replay, OpenCL Q2_K·Q3_K, Vulkan subgroup reduction, Hexagon HTP 백엔드 재구성, ZDNN flash attention. tensor parallelism이 `stepfun`·`laguna`에서 GPU 4~10개로 확대.
- `github.com/ggml-org/llama.cpp/releases/tag/v0.8.0` 원문을 직접 열어 전체 changelog를 확인했습니다.
