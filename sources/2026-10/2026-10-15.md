#### Key Points

- anthropic-sdk-python v1.13.0(2026-10-09)이 workflows·multiagent 설정·thread status filtering을 Managed Agents에 추가했다고 명시해, 플랫폼 발표와 SDK 변경이 같은 기능을 가리키는 것으로 교차 확인됩니다.
- 같은 축에서 2026-10-14에 OpenTelemetry export(beta)가 추가돼 Managed Agents 세션도 트레이싱 대상이 됐습니다(바로 앞 entry에서 다룬 Claude Code OTel 변경과는 별도로, API/Managed Agents 레이어의 관찰성 기능입니다).

#### Limitations

- v0.40.3(11 Oct): `ollama launch claude`/`ollama launch codex`의 경고 메시지를 제거하고 백그라운드 모델 업그레이드를 일시 중지했습니다.
- v0.40.2(8 Oct): 첫 실행 시 구버전 모델을 백그라운드에서 업그레이드하며 디스크에 백업을 유지하고, `ollama list` 중복 항목 버그를 고쳤습니다.
- v0.40.1(7 Oct): 클라우드 사용량·잔액 API를 프록시하고 CLI 온보딩에서 계정 단계를 제거했습니다.
- v0.40.5-rc0(14 Oct, pre-release): Metal 커스텀 커널을 CUDA로 포팅하고 Responses 히스토리에 커스텀 tool call을 추가했습니다.
- v0.40.0(25 Sep)부터 Apple Silicon에서 MLX가 기본 런타임이 됐고, decision model(`/v1/systemone`)이 v0.35.0(28 Sep)부터 추가돼 온 흐름의 연속입니다.
