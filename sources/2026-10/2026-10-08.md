#### Why It Matters

#### Key Points

- 가격(1M 토큰당, ≤100k/>100k 입력 기준): 입력 $0.10/$0.50, 출력 $0.50/$2.50, cache read $0.01/$0.05, cache write $0.125/$0.625. Haiku 4.5 대비 평균 약 75% 저렴하다고 밝혔으며(각주: 10만 토큰까지는 90%, 그 이상은 50% 절감), 새 tokenizer로 토큰 사용량 자체는 약간 늘었다고 적시했습니다.
- 벤치마크(Haiku 5.5 / Haiku 4.5 / GPT-6 Luna / Sonnet 5.5): GDPval-AA v2.1 Elo 1620/735/1437/1840, OSWorld 2.1(offline) 72.4%/15.7%/48.9%/83.9%, Terminal-Bench 4.0 39.2%/0.0%/16.4%/70.6%, Humanity's Last Exam(no tools) 45.9%/10.2%/—/56.9%. Anthropic은 복잡한 agentic coding에는 여전히 Sonnet 5.5·Opus 5.5가 낫다고 명시했습니다.
- 함께 발표된 변경: Sonnet 5.5의 cache-read 가격이 $0.20→$0.10(1M 토큰)으로 즉시 인하(50%), Max/Team 구독자에 이번 주 내 월간 API 크레딧 제공(Max 5x $100/Max 20x $200/Team 최대 $500 풀링), Python/TypeScript SDK에 computer use·browser use 베타 지원 추가.
- Cybersecurity 안전장치는 Haiku 4.5보다 엄격하고 Sonnet 5.5보다는 덜 엄격하며(여전히 침투 테스트류 차단), biology 안전장치는 Sonnet 5·5.5·Opus 5와 동일 수준이라고 밝혔습니다. AWS·Google Cloud·Microsoft Azure 및 Claude Platform API(`claude-haiku-5-5`)에서 즉시 이용 가능합니다.
