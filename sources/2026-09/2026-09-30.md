### Anthropic Claude Code, v2.1.285 배포 — `claude plugin configure`, `--desktop`, 다수 세션 안정성 수정

- source_url: https://code.claude.com/docs/en/changelog
- published: 2026-09-29
- type: changelog
- topics: agents
- status: read
- confidence: high

#### Why It Matters

- 기본 24시간 창에 포함되는 원문 직접 확인 자료입니다. 2026-09-29 로그에서 기록한 v2.1.282~284에 곧바로 이어지는 다음 버전으로, CURRENT.md Adopt의 "제한된 범위의 코딩 에이전트"·"LLM 전처리·후처리 경계" 판단과 관련된 실행 하네스 안정성 개선이 계속되고 있음을 보여줍니다.

#### Key Points

- `CLAUDE_CODE_DISABLE_WEB_FETCH` 환경변수, 현재 디렉터리에서 Claude 데스크톱 앱을 여는 `claude --desktop` 명령, 플러그인 옵션을 관리하는 `claude plugin configure`, 허용 API 프로바이더를 제한하는 `allowedProviders` managed setting, 설치 시 `<server>.<key>=<value>` 형태로 MCP 서버를 설정하는 기능이 추가됐습니다.
- 서브에이전트의 Agent 호출이 백그라운드에서 실행되던 버그, SSH를 통한 플러그인/마켓플레이스 설치가 `GIT_SSH` 설정을 무시하던 버그, 대화 컴팩션 이후 클라우드 세션이 아티팩트 갱신을 거부하던 버그, 세션 중 모델 전환 시 잘못된 출력 토큰 한도가 남던 버그, Remote Control 메시지가 Claude 응답 시작 전에 읽음 처리되던 버그 등이 수정됐습니다.

#### Limitations

- code.claude.com/docs/en/changelog 원문을 직접 열어 확인했습니다(status: read). 이 버전이 실제로 언제부터 일반 배포됐는지(문서상 날짜와 실제 롤아웃 시점의 차이)는 확인하지 못했습니다.

#### My Take

- 기존 판단과 같은 방향입니다. 2026-09-29 로그 entry 2에서 지적한 "v2.1.282~283이 두 차례 실행에서 누락됐던" 사각지대와 달리, 이번엔 바로 다음 날 기록해 공백이 생기지 않았습니다.
