#### Why It Matters

- 기본 24시간 창에 포함되는 당일 발표이자 원문을 직접 확인한 자료입니다. CURRENT.md Snapshot의 "harness와 workflow", Adopt의 "비용 효율" 흐름을 이어가는 자료로, Watchlist의 "Anthropic Claude Sonnet 5의 실제 agentic coding 성능과 비용 효율" 항목과 인접한 Opus 라인의 구체적 갱신입니다.

#### Key Points

- Anthropic이 2026-09-22 Claude Opus 5.5를 공개했습니다. 입력 100만 토큰당 $4, 출력 $20(Opus 5 대비 20% 인하), 캐시 읽기 $0.20(60% 인하)로, 전반적으로 Opus 5 대비 약 40% 비용이 절감됐다고 밝혔습니다. 처리 속도는 Opus 5 대비 30% 이상 빠릅니다.
- 벤치마크로 Terminal-Bench 4.0 66.4%, GDPval-AA v2.1 1846 Elo, OSWorld 2.0 81.8%를 제시하며, Claude Fable 5.1과 대부분의 작업에서 비슷한 성능을 낸다고 주장합니다.
- Anthropic은 자동화된 행동 감사(automated behavioral audit)에서 지금까지 테스트한 모델 중 가장 강력한 성능을 보였다고 밝혔고, METR·Frontier Design 등 외부 평가자의 사전 검증을 거쳤으며 생물학·사이버보안 영역에서 Fable 5.1과 동일 수준의 safeguard를 적용한다고 밝혔습니다. Claude Sonnet 5.5, Haiku 5.5는 향후 몇 주 내 출시 예정이라고 전해집니다.
- 독립적인 벤치마크 기관 Artificial Analysis는 Opus 5.5(max effort)가 자체 Intelligence Index에서 58점으로 지금까지 측정한 모델 중 최고점을 기록했다고 밝혔다고 전해집니다(이 부분은 artificialanalysis.ai 원문을 직접 열지 못해 검색 결과로만 교차 확인).

#### Limitations

- 핵심 발표 원문(anthropic.com/claude-opus-5-5)은 직접 열어 확인했습니다(status: read). 다만 Artificial Analysis Intelligence Index 수치(58점, 역대 최고)는 artificialanalysis.ai 원문을 열지 못해 검색 결과로만 확인했으며, 이 부분만 별도로 confidence가 낮습니다.

### OpenAI, GPT-6 Sol·Luna 공개 — GPT-5.6 대비 API 가격 반값, Astra 수준 사실성에 근접

- topics: models, infra-cost

#### Why It Matters

#### Key Points

- OpenAI가 2026-09-22 GPT-6 Sol(코딩 등 복합 작업용)과 GPT-6 Luna(대량·정형 사무 작업용)를 공개했습니다. API 가격은 GPT-5.6 Sol/Luna 대비 절반 수준으로, Sol은 입력 $2/출력 $10(1M 토큰당), Luna는 입력 $0.10/출력 $0.50이라고 전해집니다. 캐시 입력은 90% 할인된다고 전해집니다.
- GPT-6 Sol이 내부 사실성(factuality) 평가에서 이전 모델 대비 오류를 절반 수준으로 줄여 Astra급 신뢰도에 근접했다고 전해집니다.
- 벤치마크로 DeepSWE v1.1에서 GPT-6 Sol(xhigh) 68.8%(Fable 5 xhigh 69.9%와 유사) 및 AutomationBench에서 GPT-6 Sol(xhigh) 33.2% vs Claude Opus 5(max) 26.9%(작업당 $0.27)라는 수치가 전해집니다. GPT-6 Sol·Luna는 ChatGPT Work·Codex의 Plus/Pro/Business/Enterprise/Edu 사용자에게 제공되며, 아직 일반 Chat에는 제공되지 않는다고 전해집니다.

#### Limitations

- 원문(openai.com/index/introducing-gpt-6-sol-and-luna, community.openai.com 공지)은 이번 실행에서도 egress 차단으로 열지 못했습니다. TechCrunch, The New Stack, VentureBeat, the-decoder.com, GitHub Changelog 등 서로 독립된 다수 매체가 발행일(09-22)과 가격·용도 구분(Sol=코딩, Luna=사무)을 일관되게 전달해 교차 확인했습니다.
- DeepSWE v1.1, AutomationBench 수치는 OpenAI 발표를 인용한 2차 분석(digitalapplied.com, kingy.ai)에서만 확인했고, 원문의 정확한 수치·측정 조건은 확인하지 못했습니다. 원문 미확인이라 topic 문서 누적은 보류합니다.
