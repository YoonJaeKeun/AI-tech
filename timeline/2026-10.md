## One-Line Summary

- 2026-10은 **판단이 바뀐 달이 아니라 판단의 전제가 다듬어진 달**입니다. 44건 중 41건을 원문으로
  직접 확인해 이 저장소 최고의 검증률(93%)을 기록했지만, 그 44건이 단 5개 도메인에서 나왔고
  33건(75%)이 Anthropic 계열이어서, **기록의 폭은 역대 가장 좁았습니다.**

## Important Changes

이 절의 괄호 안 `MM-DD` 는 **원문 발행일**이고, 백틱으로 감싼 `2026-10-DD` 는 그 자료를 기록한
**일일 로그 파일**입니다. 두 날짜가 다른 항목이 있으므로 구분해서 읽어주세요.

- **에이전트 하네스의 운영 통제가 거의 매일 단위로 세분화됐습니다.** Claude Code v2.1.286(09-30)부터
  v2.1.312(10-27)까지 릴리스 17건을 기록했고, **전부 원문 확인**입니다. 이 달 44개 entry 중 17건,
  즉 39%가 이 한 축입니다(같은 저장소의 HIPAA managed-settings 커밋 1건을 더하면 18건).
  기능의 성격이 "모델을 더 잘 쓰는 법"에서 **"실행을 어디까지 허용하고
  무엇을 남기는가"** 로 분명히 옮겨갔습니다 — hook `onFailure:"block"`(`2026-10-09`),
  mod `tool.check`의 `decider: "person"`(`2026-10-20`),
  `claude_code.safety_event` OpenTelemetry 이벤트(`2026-10-22`),
  Enterprise custom roles로 Cloud sessions·Remote Control 권한 분리(`2026-10-26`).
- **같은 달에 "우회 경로를 여는 변경"과 "그 사용을 감사 가능하게 만드는 변경"이 나란히 나왔습니다.**
  v2.1.305(10-20)는 `sandbox.allowNestedUserNamespaces` 를 추가해 샌드박스 파일 보호를 우회하는
  경로를 공식 옵션으로 열었고(`2026-10-21`), 바로 다음 릴리스 v2.1.306~307(10-21)이
  `claude_code.safety_event` 를 추가했으며(`2026-10-22`), v2.1.308~309(10-22)는 `--mcp-config`
  파일 변조 방지와 셸 시작 파일 격리 등 **의도치 않은** 우회 경로를 다수 막았습니다(`2026-10-23`).
  앞서 v2.1.294(10-08)에서는 instruction만으로 hook을 우회할 수 있던 버그가 수정됐습니다(`2026-10-09`).
  방향이 한쪽이 아니라는 점이 중요합니다.
- **effort·비용 조절 장치가 벤더 API에서 로컬 런타임까지 전 계층으로 내려왔습니다.**
  Claude Haiku 5.5(10-07)가 Haiku 계열 최초로 조절 가능한 effort(Low~Max)를 지원하고(`2026-10-08`),
  Claude Code의 Agent tool에 `effort` 파라미터가 추가됐으며(`2026-10-07`),
  LangChain이 OpenAI Decisions API 래퍼를 미들웨어로 표준화했고(`2026-10-09`),
  Ollama가 `ollama run --ask` 로 decision model을 CLI에 넣은 뒤(`2026-10-15`)
  같은 모델 `clef` 를 자체 클라우드 서비스로 확장했습니다(`2026-10-19`).
  Claude Opus 5.5 Fast mode는 research preview를 벗어나 정식 출시됐습니다(`2026-10-16`).
- **subagent orchestration이 애플리케이션 레이어에서 벤더 네이티브 API와 하네스 기본값으로
  내려왔습니다.** Claude Developer Platform의 Managed Agents "Dynamic workflows"(beta, 10-09)는
  다수 에이전트를 phase로 묶어 실행하는 오케스트레이션 API이고(`2026-10-15`), Claude Code
  v2.1.302~303(10-18)은 **fork subagent를 여러 실행 경로에서 기본 활성화**했습니다(`2026-10-19`).
  2026-09 리뷰가 이 항목을 Trial에 둔 이유("언제 이득인가에 대한 답이 없다")는 10월에도 답을
  받지 못했습니다. 아래 Radar Changes를 보세요.
- **에이전트 생태계의 핵심 표준이 벤더 소유에서 벗어나는 두 번째 사례가 나왔습니다.**
